# HTML 本页预览动态图片修复

日期：2026-11-02。

## 原因

HTML 预览原先只在打开前转换静态图片。页面脚本通过 innerHTML、Image.src 或 setAttribute 动态生成 H/logo-48.png 等相对地址时，没有经过图片内嵌处理；srcdoc 又继承编辑器页面的地址，导致请求落到编辑器根路径并被预览 CSP 阻断。no-referrer 是请求的引用来源策略，并非阻断原因。

## 修复

| 范围 | 行为 |
| --- | --- |
| 动态图片 | 插入沙箱加载器，支持 innerHTML、insertAdjacentHTML、Image.src、setAttribute 和后续 DOM 插入 |
| 路径 | 由父页面携带原 Markdown 和被预览 HTML 的引用，继续通过现有 html-images 接口按 HTML 所在位置解析 |
| 显示 | 图片完成权限校验后转成 data URL，再交回对应沙箱图片节点；原图链接继续使用本页图片弹层 |
| 批量 | 每批最多32个引用，单次预览最多256个不同引用，重复图片复用结果 |
| 竞态 | 主题切换或来源变化后，旧请求不会覆盖新图片；关闭或切换预览后旧响应失效 |
| 隔离 | 保留 allow-scripts 沙箱、no-referrer 和仅允许 data/blob 图片的 CSP；不授予同源权限 |

主要修改：web/resources.js、tests/reference-privacy.test.cjs。代码与本记录均同步到 github/Local-Markdown-Editor。
